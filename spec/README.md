# HIDE specification

[`hide-1.md`](hide-1.md) is the **current** specification: the HIDE 1 wire format, release
candidate 0.9.0. It covers the container, signatures, HIDE-Sign, key files, identity logs, epoch
chains, transparency, the MLS binding, the registries and the known limitations of the 1.0 freeze,
and separates the frozen format from implementation-defined artefacts (armor, challenges, detached
signatures, the epoch keystore).

[`hide-0.1.md`](hide-0.1.md) is superseded. It records the 0.1–0.8 wire; everything it describes
remains readable under `hide-1.md`.
