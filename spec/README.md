# HIDE specification

[`hide-0.1.md`](hide-0.1.md) is the **current** wire-format specification, covering versions 0.1
through 0.7. The filename is historical: the container layout it names has not changed since 0.1,
and the later versions (signatures, identity, epoch, transparency, MLS binding) were appended as
sections rather than forked into new files. Its status block lists what each version added.
